# 학교급식 식단 자동변환

나이스 HWPML 월간식단과 배포용 HWPX 템플릿을 브라우저 안에서만 처리해
새 HWPX 파일로 내려받는 정적 웹앱입니다. 로그인, 서버 업로드, 서버 저장을
사용하지 않습니다.

## 지원 형식

- 원본: 나이스에서 내려받은 HWPML(XML) 형식의 `.hwp`
- 템플릿: ZIP/XML 기반 `.hwpx`
- 출력: `{월}월 식단(배포용).hwpx`

템플릿은 `날짜 행 + 메뉴 행` 기본형과 `날짜 행 + 메뉴 행 + 영양량 행`
분리형을 자동 판별합니다. 주차마다 행 구성이 다른 템플릿은 잘못된 변환을
막기 위해 중단합니다. 월~금 머리글은 글자뿐 아니라 그림이어도 보존되며,
요일별 칸이 내부 표에서 여러 열을 가로 병합한 형태도 지원합니다. 단,
월~금 각각의 날짜·메뉴·영양량 칸은 서로 분리되어 있어야 합니다. 달력 칸
안의 이전 달 날짜·메뉴·영양량·그림·안내는 새 달 내용으로 교체되므로,
계속 보존할 로고·QR·원산지·안내문은 달력 표 밖의 별도 영역에 두어야 합니다.

기존 메뉴 예시에서 알레르기 표기도 별도로 판별합니다. 괄호형
`메뉴(5.6.9)`과 점표기형 `메뉴 5.6.9.`을 지원하며, 화면에서 자동 감지
결과를 확인하거나 직접 형식을 선택할 수 있습니다. 표 구조와 알레르기
표기는 독립적으로 처리됩니다.

템플릿에 `발행일` 또는 `발행일자`가 있으면 나이스 원본의 연·월로 자동
변경합니다. `2026년 6월`, `2026. 6.`, `6월` 형식을 지원하며, 발행일이
없는 템플릿은 그대로 둡니다.

바이너리 HWP 템플릿은 브라우저에서 직접 수정할 수 없습니다. 첨부된 원본
템플릿을 분석해 재구성한 `dist/assets/배포용_템플릿.hwpx`를 포함했습니다.

## 로컬 실행

정적 파일 서버로 `dist` 폴더를 열면 됩니다. 예:

```bash
python -m http.server 4173 --directory dist
```

## 실제 파일 변환 테스트

테스트용 Node 의존성을 준비한 뒤 나이스 원본 경로를 지정해 실행합니다.

```bash
MEAL_SOURCE_PATH="/path/to/(202610)월간식단.hwp" node tests/conversion.test.mjs
```

## 변환 규칙

PC 버전 v5.6의 분류 키워드와 순서를 그대로 사용합니다. 기본값은 메뉴명
템플릿 크기·자간 -10, 알레르기 번호 9pt·자간 -10, 영양량 9pt·자간 -20,
문단 줄간격 140%입니다. `(자율)` 메뉴의 알레르기 번호는 기본적으로
유지하고 `* 에너지/단백질/칼슘/철` 설명문만 제거합니다.

템플릿을 선택하면 기존 식단 예시에서 줄간격, 알레르기·영양량 크기와 자간,
자율식 알레르기 유지 여부를 먼저 감지해 화면에 표시합니다. 감지할 예시가 없는
항목만 위 기본값을 사용합니다. 그 후 `서식 설정`에서 값을 바꿀 수 있으며,
템플릿 기억하기를 선택하면 실제 적용한 설정도 템플릿과 함께 저장됩니다.
