# 첨부 파일 구조 분석

## 나이스 원본 `(202610)월간식단.hwp`

- 확장자는 `.hwp`지만 실제 내용은 UTF-8 HWPML 2.1 XML입니다.
- 전체 7개 표 중 월간 식단은 4번째 표입니다.
- 월간 표는 11행 × 6열이며 첫 열은 급식 구분, 2~6열은 월~금입니다.
- 첫 행은 요일, 이후 `날짜행 → 중식행`이 5주 반복됩니다.
- `조회년월: 2026년 10월`과 평일 중식 22일을 추출했습니다.
- 각 중식 셀은 메뉴별 `<P>` 문단으로 구성되어 있어 문단 경계를 메뉴 줄로 사용합니다.

## 첨부 템플릿 `배포용_템플릿.hwp`

- 첨부 파일은 HWPX가 아니라 HWP 5.x OLE 바이너리 문서입니다.
- 본문에는 표가 2개 있습니다.
  - 월간 식단표: 12행 × 5열, 요일 1행 + 날짜/식단 5주 + 병합 안내 1행
  - 원산지 표시표: 2행 × 10열
- 월간 표의 날짜·식단 칸은 병합되지 않았고, 하단 안내행만 5열 병합입니다.
- 메뉴 문단은 8pt 중심, 날짜·알레르기·영양량은 9pt 중심이며 줄간격은 140%입니다.

바이너리 HWP는 브라우저에서 ZIP/XML로 직접 수정할 수 없으므로 같은 표 구조,
학교명, 안내문과 원산지 표를 재구성한 `dist/assets/배포용_템플릿.hwpx`를 만들었습니다.
웹앱에서는 이 파일 또는 사용자가 한글에서 HWPX로 저장한 자체 템플릿을 사용합니다.

## 변환 검증 결과

- 2026년 10월과 평일 달력 5주 생성 확인
- 중식 22일 추출 확인
- 행사일 2일, 5일 반영 확인
- PC v5.6 메뉴 분류 순서 확인
- `(자율)` 뒤 알레르기 번호 기본 유지 및 사용자 선택 제거 확인
- 알레르기 번호 9pt/자간 -10, 영양량 9pt/자간 -20 기본값 확인
- 메뉴명 기본 크기/자간 -10 및 문단 줄간격 140% 확인
- 줄간격, 알레르기·영양량 크기와 자간을 사용자 설정값으로 변환하는 기능 확인
- 템플릿의 기존 메뉴·영양량 예시에서 서식값을 먼저 감지하고 사용자 변경은 이후 적용 확인
- 결과 HWPX ZIP 패키지와 `header.xml`, `section0.xml` 스키마 검증 통과
- 군위초 템플릿의 그림형 월~금 머리글 및 27열 가로 병합 달력 인식 확인
- 그림·바이너리 리소스와 전체 셀 병합 구조가 변환 전후 동일함을 확인
- 발행일이 있는 템플릿은 원본 식단의 연·월로 변경하고 기존 글자 서식 유지 확인
